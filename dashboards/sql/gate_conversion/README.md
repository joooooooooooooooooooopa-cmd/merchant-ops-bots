# Дашборд «Гейт Конверсия» (Metabase Acme)

На одном экране почасовая конверсия по всем **рублёвым** гейтам,
отдельным «окошком» на каждый гейт (orion, lyra, vega и т.д.).

- **Дашборд:** `https://metabase.example.com/dashboard/7` («Гейт Конверсия», коллекция «Бизнес» id=22).
- **Карточки** — в подпапке «Гейт Конверсия — карточки» (id=26) внутри «Бизнес» (не валяются в корне).
- **Основной дашборд (id=4) не трогали.**

## Что внутри
- **Сводная таблица** «Гейты — сводка за период» (card 128): Заявок / Выдано / Оплачено + три конверсии
  (в выдачу, в успех, оплата/заявки) + Оборот. Цветовая шкала на колонке «оплата/заявки».
- **6 окошек-гейтов** (cards 129–134): orion, sigma, vega, lyra, altair, rigel.
  Комбо-график по часам (МСК): столбики **Заявок** (серый) + **Оплачено** (зелёный),
  линия **Конверсия = оплата/заявки, %** (синяя, правая ось).
- **Параметр «Период, часов»** (по умолчанию 24) — скользящее окно `now() - N часов`, общий для всех карточек.

## Формулы (как у всех ботов Acme)
- Успех (SUCC) = `payment_status_id IN (3,6)`.
- Выдача (ISS) = реквизит выдан OR `data->route_result->>status='success'` OR SUCC.
- Гейт = `primary_payment_gate_id` → `pricing_paymentgate.iname`.
- Тесты вычищены (is_test=false + мерчи с 'test' в имени). Только `currency_code_id='RUB'`.
- Время МСК через `AT TIME ZONE 'Europe/Moscow'`; окно по `now()` (абсолютное, без ночного TZ-бага).

## Почему линия = оплата/заявки (а не оплата/выдано)
У orion/vega/lyra выдача ≈ заявкам, поэтому разницы нет. Но у **sigma** из всех заявок
выдаётся лишь малая доля, при этом из выданного оплачивается почти всё. Метрика «оплата/выдано» спрятала бы
проблему (показала бы почти 100%), а «оплата/заявки» честно показывает низкую цифру. В сводной таблице есть все три.

## Гейты
Включены рублёвые гейты с реальным трафиком. Исключены `mock_gate` (тест) и неактивные гейты с единичным трафиком.
Новый гейт появится — добавить строку в `GATES` в `build_dashboard.py` и перезапустить.

## Как пересобрать / править
1. Свежая кука: DevTools → Network → запрос `api/...` → Copy as cURL → строку после `-b` положить в `cookie.txt`
   (живёт ~2 часа). Кука — только локально, в репо/память не уходит.
2. `python3 build_dashboard.py` (создаёт карточки и дашборд заново — для правок существующего лучше менять через API по id).
- `mb.py` — хелпер API (`mb.show("SELECT ...")` для проверок, `mb.api(method,path,body)`).
